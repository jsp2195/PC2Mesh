# Pinned to the versions this checkpoint was trained, scored and verified with.
# Everything runs offline: no weights are downloaded and no network call is made
# at any stage. `python main.py verify` prints the version it actually imported
# for each of these, so a drift is visible rather than silent.

# --- torch -------------------------------------------------------------------
# CUDA is OPTIONAL. A CPU-only build runs the whole pipeline; decoding a 128^3
# grid is just slower (order a minute per shape instead of a couple of seconds).
# The build verified here is 2.5.1+cu121. A plain `pip install -r requirements.txt`
# takes whatever build your index defaults to, which is usually what you want. To
# pin one explicitly:
#   CUDA 12.1 : pip install torch==2.5.1 --index-url https://download.pytorch.org/whl/cu121
#   CPU only  : pip install torch==2.5.1 --index-url https://download.pytorch.org/whl/cpu
torch==2.5.1

                          # 4000-face decimation does not run without it
